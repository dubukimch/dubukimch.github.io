REGRESSION
2026.10.23

일곱 작업 공간을 한눈에

로컬 UI 캡처와 역할별 설명을 최신 구성으로 정리했습니다. AssetHub는 로컬 초안·온톨로지 구현 단계이며 운영 승인 API와 표준 AAS runtime은 미완료입니다.

LOCAL UI

화면은 로컬 개발 환경에서 직접 캡처했습니다. PLC → Gateway → Twin 읽기 흐름은 2026-10-09 격리 fixture에서 확인했습니다. 일곱 제품의 운영 통합, 실장비 제어, 정상 OEE 생산 흐름과 AssetHub 승인 API는 확인 범위에 포함하지 않습니다.

실행과 데이터의 경계

격리 시뮬레이터·빈 DB fixture·로컬 초안을 사용합니다. OEE NoData, Kafka 미연결, Fake 생성기와 실제 읽기 출처를 구분합니다. 실장비 명령은 이 포트폴리오의 검증 경로에 포함하지 않습니다.

제작과 공개의 범위

자체 HTML/CSS/JavaScript와 직접 캡처한 화면을 사용합니다. 외부 AI API·새 유료 서비스·외부 폰트가 필요하지 않습니다. 로컬 검증과 GitHub 원격 게시 상태는 별개입니다.

DELIVERY NOTES

구현 다음에 남은 검토

운영 인증·승인된 자산 매핑 소비 계약·정상 OEE 시계열 경로·재연결과 지연 회귀가 남아 있습니다. 전체 의존성·native 자산·NOTICE의 배포 조건도 별도 검토 대상입니다. 로컬 UI와 이 문서는 제품의 운영 배포 승인이나 AAS 표준 적합성 판정을 선언하지 않습니다.
