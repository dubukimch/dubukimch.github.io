THE PROBLEM

해결하려는 과제

상태·알람·이력·효율을 질문할 때 답변의 출처, 품질과 불확실성도 함께 확인해야 합니다.

THE WORKSPACE

구현한 작업 공간

제품별 읽기 adapter와 조회 도구로 근거를 구성합니다. 이번 로컬 실행은 PLC/Twin HTTP 소스를 구성하고 다른 네 출처는 Mock으로 유지합니다. 답변·지식·음성은 Fake이며 실제 조회 성공 여부는 각 답변의 출처와 품질에서 확인합니다.

  • 역할과 논리 자산 선택
  • 실제 구성 소스 종류와 출처 표시
  • 답변·근거 복사와 Markdown 내보내기
  • 인증·세션·실패 상태 경계

DESIGN DECISIONS

설계에서 지킨 것

  • 설비 제어 도구를 제공하지 않습니다.
  • 출처·품질·Mock과 불확실성을 표시합니다.
  • 조회 권한·세션·입력 길이를 검사합니다.
