PROJECT 06 / READ / EXPLAIN

Industrial Assistant

현장의 질문에 출처가 있는 답변을

읽기 전용 근거 조회·출처 설명.NET 10 · Python · Fake/Mock adapters

THE PROBLEM

해결하려는 과제

설비 상태·알람·이력·효율을 질문할 때 답변의 출처와 품질, 불확실성을 함께 확인해야 합니다.

IMPLEMENTATION

구현한 작업 공간

여섯 제품별 읽기 adapter와 조회 도구 경계를 둡니다. 이번 실행은 Fake/Mock만 사용하며 외부 LLM API, 모델 다운로드, 음성·아바타 생성 기능을 호출하지 않습니다.

  • 역할·논리 자산 선택
  • 상태·알람·이력·OEE 조회 adapter
  • 출처와 품질을 보여주는 채팅 UI
  • 인증·세션·길이·CSP 경계

DESIGN DECISIONS

설계 판단

  • 설비 제어 도구를 제공하지 않습니다.
  • 출처·품질·Mock/불확실성 표기를 유지합니다.
  • client key·세션 일치·입력 길이를 검사합니다.
VERIFIED / 2026.10.05

확인된 동작

Docker Fake/Mock의 일반 대화·설비 상태·알람 경로와 잘못된 키·세션·길이 제한 PASS. 브라우저에서 조회 전용/Mock 안내와 빈 키 입력 보호를 확인했습니다.

NEXT ITERATION

추가 개선 범위

실제 읽기 출처의 provenance·결측·staleness 연결과 로컬 지식 저장소의 라이선스·데이터 권한 검토가 남아 있습니다.

내부 네트워크의 HTTP/WebSocket·MySQL 인증과 로컬 UI fixture를 검증했습니다. 실장비, 전체 6개 출처의 데이터 통합, 외부 AI 품질은 이번 검증 범위에 포함하지 않습니다.
