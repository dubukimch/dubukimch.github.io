THE WORKSPACE

구현한 작업 공간

CSV/JSON 수집, 분석 그리드, DB 탐색, 스트림 관측과 보고서를 제공합니다. 출처를 확인하는 읽기 작업 공간으로 OEE 계산을 중복하지 않습니다.

  • CSV/JSON과 SVG 차트
  • 분석 그리드와 데이터 탐색
  • 제조 데이터·스트림 관측
  • 템플릿 보고서와 출처 표시

DESIGN DECISIONS
