PROJECT 05 / EXPLORE / REPORT

DataNexus Analytics

데이터를 탐색하고 출처를 비교하다

읽기 전용 탐색·비교·보고서.NET 8 · Blazor · SignalR · SVG

THE PROBLEM

해결하려는 과제

파일·DB·스트림의 데이터를 비교하면서 원본 품질과 계산 제공자를 놓치기 쉽습니다.

IMPLEMENTATION

구현한 작업 공간

CSV/JSON 수집, 분석 그리드, DB 탐색, 스트림 관측과 보고서 화면을 제공합니다. OEE 계산을 중복하지 않고 데이터와 출처를 확인하는 읽기 작업 공간으로 설계했습니다.

  • CSV/JSON 수집과 SVG 차트
  • 분석 그리드와 데이터 탐색
  • 제조 데이터·스트림 관측
  • 템플릿 보고서와 출처 표시

DESIGN DECISIONS

설계 판단

  • 외부 LLM 없이 분석과 템플릿 보고서를 제공합니다.
  • 데모 데이터에는 DEMO 출처를 표시합니다.
  • .NET 8에 맞는 SignalR 버전으로 CSV 업로드 ABI 오류를 해결했습니다.
VERIFIED / 2026.10.05

확인된 동작

Docker 웹/BlazorPack 바인딩 PASS. 브라우저에서 합성 CSV 4행 업로드·SVG 차트 생성·분석 그리드 반영을 확인했습니다.

NEXT ITERATION

추가 개선 범위

대용량·취소·동시 import와 사용자별 범위, 캐시 상한, 파일 드롭 및 상세 모바일 동작을 확대 검증합니다.

내부 네트워크의 HTTP/WebSocket·MySQL 인증과 로컬 UI fixture를 검증했습니다. 실장비, 전체 6개 출처의 데이터 통합, 외부 AI 품질은 이번 검증 범위에 포함하지 않습니다.
