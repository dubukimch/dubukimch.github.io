THE PROBLEM

해결하려는 과제

효율 수치만으로는 결측, 데이터 품질, 생산 맥락과 계산 구간의 신뢰도를 설명하기 어렵습니다.

THE WORKSPACE

구현한 작업 공간

상태·카운터와 생산 맥락을 결합하는 계산 경계를 두고 기간 결과와 coverage/revision을 제공합니다. 인증과 역할에 따라 조회·관리 기능을 구분합니다.

  • 기간별 A/P/Q/OEE와 신뢰도
  • 데이터 소스와 계산 규칙
  • Admin · Viewer 권한 경계
  • 인증·CORS와 실패 상태 안내

DESIGN DECISIONS

설계에서 지킨 것

  • OEE 계산의 권위는 한 제품에 둡니다.
  • 결측과 NoData를 유효한 0% 결과와 구분합니다.
  • 기존 계정과 암호 해시를 보존하고 기본 bootstrap을 비활성화합니다.

EVIDENCE & SCOPE

확인된 동작

현재 실행은 새 로그인 UI를 확인했으며 API·DB 연결 성공은 확인하지 못했습니다. 과거 2026-10-05 실제 MySQL 인증 25개, .NET 35개 PASS와 2026-10-09 NoData fixture는 별도 검증입니다. 정상 생산 지표 통합을 입증하지 않습니다.

NEXT ITERATION

다음 개선 범위

정상 Timescale/Redis 경로, 승인된 sample/context fixture, 지연·중복·결측과 revision 근거를 확대 검증합니다.

화면은 로컬 개발 환경에서 직접 캡처했습니다. PLC → Gateway → Twin 읽기 흐름은 2026-10-09 격리 fixture에서 확인했습니다. 일곱 제품의 운영 통합, 실장비 제어, 정상 OEE 생산 흐름과 AssetHub 승인 API는 확인 범위에 포함하지 않습니다.
