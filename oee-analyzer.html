THE PROBLEM

해결하려는 과제

효율 수치만으로는 결측, 데이터 품질, 생산 맥락과 계산 구간의 신뢰도를 설명하기 어렵습니다.

THE WORKSPACE

구현한 작업 공간

상태·카운터와 생산 맥락을 결합하는 계산 경계를 두고 기간 결과와 coverage/revision을 제공합니다. 인증과 역할에 따라 조회·관리 기능을 구분합니다.

  • 기간별 A/P/Q/OEE와 신뢰도
  • 데이터 소스와 계산 규칙
  • Admin · Viewer 권한 경계
  • 인증·CORS와 실패 상태 안내

DESIGN DECISIONS

설계에서 지킨 것

  • OEE 계산의 권위는 한 제품에 둡니다.
  • 결측과 NoData를 유효한 0% 결과와 구분합니다.
  • 기존 계정과 암호 해시를 보존하고 기본 bootstrap을 비활성화합니다.

INSIDE OEEANALYZER

화면으로 살펴보는 분석 흐름

2026년 9월 16일 로컬 시뮬레이터를 연결해 직접 캡처한 분석·설정 화면입니다. 로그인 화면은 10월 23일 개편된 UI입니다.

01 / DATA SOURCES

생산 신호를 업무 태그로 연결

Gateway의 OPC UA endpoint와 노드를 등록하고 생산량·불량 수·설비 상태·카운터 세대를 연결합니다. 어떤 신호가 계산에 쓰이는지 설정 화면에서 추적할 수 있습니다.

Total_Count · Reject_Count · Machine_State · Counter_Epoch

02 / PROCESSING RULES

설비에 맞는 계산 규칙 구성

생산량·불량·상태 태그를 OEE 계산에 매핑하고 이상 주기시간을 지정합니다. 같은 작업 공간에서 MCC 센서의 경고·위험 임계값도 별도로 구성합니다.

업무 태그 매핑 · Ideal Cycle Time · MCC 임계값

03 / WINDOW LEDGER

결과와 계산 근거를 함께 확인

선택한 구간의 A/P/Q/OEE뿐 아니라 coverage, 생산 수량, revision과 진단 결과를 나란히 읽습니다. 캡처에서는 OEE 88%, coverage 100%, Final 상태와 Complete 진단을 확인할 수 있습니다.

A 100% · P 88% · Q 100% · revision 2776

PRODUCTION CONTEXT

생산 맥락과 만나는 분석 결과

TwinForge의 External OEE 패널에서 설비·작업지시·제품·context ID와 OEEAnalyzer 결과를 함께 봅니다. 이 화면은 동기화 도중의 Provisional 상태로, 위 Final 결과와 조회 시점이 다릅니다.

SIGN IN & ACCESS

로그인에서 시작하는 작업 공간
