PROJECT 03 / CALCULATE / EXPLAIN

OEEAnalyzer

생산 효율에 계산 근거를 더하다

기간 A/P/Q/OEE·coverage·revision 계산.NET 8 · React · MySQL · TimescaleDB

THE PROBLEM

해결하려는 과제

효율 수치 하나만으로는 결측, 품질 저하, 생산 맥락과 계산 구간의 신뢰도를 설명하기 어렵습니다.

IMPLEMENTATION

구현한 작업 공간

원본 카운터·상태와 생산 맥락을 결합하는 계산 경계를 두고 기간 결과와 coverage/revision을 제공합니다. 인증과 역할에 따라 조회·관리 기능을 구분합니다.

  • 기간별 A/P/Q/OEE와 신뢰도
  • 데이터 소스·계산 규칙 관리
  • 관리자·Viewer 역할 경계
  • 허용 origin 목록 기반 CORS

DESIGN DECISIONS

설계 판단

  • 다른 제품이 OEE를 다시 계산하지 않도록 소유권을 둡니다.
  • Bootstrap은 기본 비활성, 빈 Users에만 명시적 관리자를 생성합니다.
  • 손상된 암호 해시는 로그인 거부로 처리하고 기존 정상 해시는 보존합니다.
VERIFIED / 2026.10.05

확인된 동작

실제 MySQL 인증·권한·계정 보존·정리 25개 PASS, .NET 테스트 35개 PASS. Docker 401/400/503 및 CORS 경계 PASS.

NEXT ITERATION

추가 개선 범위

정상 Timescale/Redis 경로와 지연·중복·결측에 대한 계산 근거 및 6개 출처 통합 검증이 남아 있습니다.

내부 네트워크의 HTTP/WebSocket·MySQL 인증과 로컬 UI fixture를 검증했습니다. 실장비, 전체 6개 출처의 데이터 통합, 외부 AI 품질은 이번 검증 범위에 포함하지 않습니다.
