02 / CONNECTED BY DESIGN

값은 원본에서.
의미는 관계에서.

PLC와 Gateway는 신호의 출처를, Twin과 OEE는 생산 맥락과 계산 책임을 지킵니다. DataNexus와 Assistant는 결과를 읽고 설명합니다.

제품 사이의 계약 살펴보기 →

원본을 보존하는 데이터 경로

값과 함께 품질·원본 시각·수신 시각을 읽습니다. 연결되었다는 사실과 유효한 값이 있다는 사실을 구분합니다.

한곳에서 소유하는 계산

OEE는 계산 결과를, Twin은 생산 맥락을 소유합니다. 읽기 제품이 효율을 다시 계산하거나 설비를 제어하지 않습니다.

식별과 의미를 위한 AssetHub

공통 ID와 소스 tuple을 로컬 초안에 연결합니다. 기존 실행 경로와 독립적으로 자산·개념·관계를 검토합니다.

A SHARED LOCAL WORKSPACE

일곱 경로의 응답을 한 화면에서.

AssetHub 연결 작업 공간에서 고정된 로컬 경로의 HTTP 상태·응답 시간·관측 시각을 확인합니다. 제품 사이 데이터 전송과 업무 흐름의 성공 여부는 별도로 검증합니다.

2026.10.23

일곱 작업 공간을 한눈에

로컬 UI 캡처와 역할별 설명을 최신 구성으로 정리했습니다. AssetHub는 로컬 초안·온톨로지 구현 단계이며 운영 승인 API와 표준 AAS runtime은 미완료입니다.

LOCAL UI
