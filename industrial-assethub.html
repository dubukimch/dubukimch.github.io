THE PROBLEM

해결하려는 과제

제품마다 설비 이름·태그·개념이 다르면 서로 다른 원본을 같은 자산으로 오인하거나 출처를 잃을 수 있습니다.

THE WORKSPACE

구현한 작업 공간

자산 초안, 로컬 개념 사전, 설명 가능한 문자열 매칭과 의미 관계를 편집하는 온톨로지 스튜디오입니다. 원본 소스 tuple을 보존하며 기존 데이터 경로에 필수 의존성을 추가하지 않습니다.

  • 자산 초안과 계층·관계 편집
  • 6개 로컬 개념과 매칭 근거
  • partOf · observes 관계와 제약 검사
  • 일곱 로컬 경로의 HTTP 관측 대시보드

DESIGN DECISIONS

설계에서 지킨 것

  • 식별·의미·소스 매핑을 기존 여섯 제품의 실행 책임과 분리합니다.
  • 로컬 검토 통과와 운영 승인·표준 적합성을 구분합니다.
  • 매칭 점수는 문자열 순위이며 확률이나 자동 승인 판정이 아닙니다.

FROM OVERVIEW TO HANDS-ON

직접 사용하는 순서

자산의 소스와 의미를 연결하고 로컬 상태 확인하기

  1. 01온톨로지 작업공간 둘러보기
  2. 02교육용 자산의 원본 선언
  3. 03초안 저장과 식별자 확인
