THE PROBLEM

해결하려는 과제

실제 PLC 접속 환경과 설비 동작을 반복 재현하기 어려워 상위 수집·분석 시스템의 개발과 검증이 늦어집니다.

THE WORKSPACE

구현한 작업 공간

가상 제조 셀, Ladder 실행, 드라이버와 태그, 메모리 매핑을 하나의 작업 공간에서 다룹니다. 상위 제품이 읽는 상태와 카운터의 원본을 제공합니다.

  • 가상 제조 셀와 Ladder I/O
  • 드라이버 · 태그 · 메모리 매핑
  • 품질과 관측 시각 모니터
  • 입력에서 출력까지의 동작 확인

DESIGN DECISIONS

설계에서 지킨 것

  • 설비 상태와 제어 명령을 별도 경계로 다룹니다.
  • 통신 드라이버와 태그 구성을 분리합니다.
  • 시뮬레이터 값을 실제 생산 데이터로 표시하지 않습니다.
