PROJECT 01 / SOURCE / PROTOCOL LAB

PLC Simulation

장비 없이 시작하는 산업 프로토콜 실험실

원본 상태·생산 카운터·명령 Ack.NET 8 · ASP.NET Core · Modbus TCP

THE PROBLEM

해결하려는 과제

상위 수집·분석 시스템을 만들 때 실제 PLC의 접속 환경과 동작 상태를 반복 재현하기 어렵습니다.

IMPLEMENTATION

구현한 작업 공간

가상 설비와 Ladder 실행 화면, 드라이버·태그·메모리 매핑을 하나의 웹 작업 공간에서 다룹니다. 생산 상태와 명령 수락 결과의 원본을 소유합니다.

  • 가상 제조 셀과 Ladder 입력/출력
  • PLC 노드와 드라이버 설정
  • 태그 모니터와 메모리 매핑
  • 명령 수락과 상태 피드백

DESIGN DECISIONS

설계 판단

  • 원본 상태와 제어 명령을 구분합니다.
  • 통신 드라이버와 태그 구성을 분리합니다.
  • 가상 설비 동작을 실제 장비 데이터로 표시하지 않습니다.
VERIFIED / 2026.10.05

확인된 동작

Docker 웹 응답과 업로드 거부 경로 PASS. 브라우저에서 가상 RUN → X0 입력 ON → 모터 Y0 ON 반응을 확인했습니다.

NEXT ITERATION

추가 개선 범위

프로토콜별 경계·결측·지연 시험을 확대하고 명령 UUID/TTL와 감사 증거를 강화합니다.

내부 네트워크의 HTTP/WebSocket·MySQL 인증과 로컬 UI fixture를 검증했습니다. 실장비, 전체 6개 출처의 데이터 통합, 외부 AI 품질은 이번 검증 범위에 포함하지 않습니다.
