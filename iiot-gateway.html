THE PROBLEM

THE WORKSPACE

구현한 작업 공간

Channel · Device · Tag 구성과 OPC UA 정보 모델로 수집 경계를 제공합니다. 연결, 태그 품질, 이력과 알람을 운영 UI에서 탐색합니다.

  • Channel · Device · Tag 모델
  • Historian · Aggregation · Alarm 구성
  • OPC UA 정보 모델과 품질
  • 제품별 책임을 구분하는 운영 콘솔

DESIGN DECISIONS

설계에서 지킨 것

  • 수집과 품질·시각·라우팅을 소유합니다.
  • OEE 계산과 자연어 설명은 각 담당 제품에 둡니다.
  • 비명령 노드의 쓰기 경계와 읽기 값의 provenance를 보존합니다.
