PROJECT 04 / CONTEXT / DIGITAL TWIN

TwinForge

생산 맥락과 공간을 연결하는 가상 공장

3D·워크플로·MES 생산 맥락.NET 8 · React · Three.js · OPC UA

THE PROBLEM

해결하려는 과제

설비 데이터와 작업 흐름, 생산 맥락이 분리되어 있으면 상태를 공간·공정 단위로 이해하기 어렵습니다.

IMPLEMENTATION

구현한 작업 공간

설비 탐색과 3D 현장, 운영 대시보드 및 워크플로 UI를 제공합니다. External 데이터가 없으면 실시간 수치를 비워 두고 시설 미리보기로 구분합니다.

  • Three.js 3D 제조 현장
  • 설비 탐색과 운영 데이터 패널
  • 워크플로와 노드 매핑
  • External 상태와 결측 표시

DESIGN DECISIONS

설계 판단

  • MES 맥락을 제공하고 OEE 권위 결과를 활용합니다.
  • 미수신 External 값에 임의 수치를 대입하지 않습니다.
  • OPC UA를 MIT 버전으로 전환하고 테스트 인증서 최소 키 2048비트를 보존했습니다.
VERIFIED / 2026.10.05

확인된 동작

실제 두 로컬 OPC UA 서버를 포함한 테스트 45개 PASS. Docker 웹/health PASS. 브라우저에서 3D 미리보기·미수신 표시·제어 비활성을 확인했습니다.

NEXT ITERATION

추가 개선 범위

UUID/TTL/ACK 감사 회귀, 장애 중 재연결·중복 방지 및 큰 프런트엔드 번들 분리가 남아 있습니다.

내부 네트워크의 HTTP/WebSocket·MySQL 인증과 로컬 UI fixture를 검증했습니다. 실장비, 전체 6개 출처의 데이터 통합, 외부 AI 품질은 이번 검증 범위에 포함하지 않습니다.
