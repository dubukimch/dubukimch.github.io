PROJECT 03 / CONTEXT & DIGITAL TWIN

TwinForge

데이터에 공간과 생산 맥락을 더하다

.NET 8ReactThree.jsOPC UA
THIS PRODUCT OWNS3D 현장 · 워크플로 · MES 생산 맥락

THE PROBLEM

해결하려는 과제

설비 수치와 작업 흐름, 생산 맥락이 흩어져 있으면 상태를 공간과 공정 단위로 이해하기 어렵습니다.

THE WORKSPACE

구현한 작업 공간

설비 탐색, 3D 현장, 운영 대시보드와 워크플로 UI를 제공합니다. External 데이터가 없을 때는 미수신 상태를 드러내고 시설 미리보기와 구분합니다.

  • Three.js 3D 제조 현장
  • 설비 탐색과 운영 데이터 패널
  • 워크플로와 노드 매핑
  • External 품질 · 결측 · 연결 상태

DESIGN DECISIONS

설계에서 지킨 것

  • 생산 맥락을 제공하고 OEE 권위 결과를 활용합니다.
  • 미수신 External 값을 임의 수치로 채우지 않습니다.
  • OPC UA 연결 상태와 실제 값 수집 상태를 분리합니다.

FROM OVERVIEW TO HANDS-ON

직접 사용하는 순서

3D 모의 공장에서 설비를 찾고 운영 근거 읽기

  1. 01공장 데이터의 출처 읽기
  2. 02모의 공장 시작·정지하기
  3. 03설비 검색과 구역 필터
